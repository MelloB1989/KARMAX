# Fleet console mockups

The approved visual direction (A, Mission Control) and the first look at the 3D office (D),
as their source. They were drawn with the real fleet's data at 18:53 IST on 2026-10-11.

- Markup is HTML with `{{hole}}` lookups into the `renderVals()` data at the bottom of each file.
- Read them for layout, density, palette, type and motion. The panel's data comes only from the
  console's snapshot, never from these files.
